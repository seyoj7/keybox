Keybox NSIS progress plug-in.

Based on TitlebarProgress NSIS plugin, version 20091110.
Original source: https://nsis.sourceforge.io/TitlebarProgress_plug-in
Original author: AndersK
Original license: zlib/libpng

The Keybox version maps three NSIS extraction/copy progress phases into one
continuous progress bar and displays the combined percentage in the installer
window title. Source is in titprog.cpp.
